# Basic Chatbot Using Python

## Description

This project is a simple rule-based chatbot developed using Python. It interacts with users through predefined messages and replies.

## Features

* Greets the user with "Hi!"
* Responds to "How are you?" with "I'm fine, thanks!"
* Ends the conversation when the user types "bye".
* Displays a default response for unknown messages.
* Supports uppercase and lowercase input.

## Technologies Used

* Python 3
* VS Code

## Concepts Used

* Functions
* If-elif-else statements
* While loop
* User input and output

## How to Run

1. Install Python 3.
2. Open the project folder in VS Code.
3. Open the terminal.
4. Run the following command:

```bash
python basic_chatbot.py
```

5. Type `hello`, `how are you`, or `bye` to interact with the chatbot.
